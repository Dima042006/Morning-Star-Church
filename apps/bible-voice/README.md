# Bible Voice — вірші з Біблії за голосом проповідника

Панель оператора + окреме вікно для проєктора. Опублікована разом із сайтом церкви:
**https://dima042006.github.io/Morning-Star-Church/bible/**

## Як працює
1. «Почати слухати» (або кнопка пульта) — Chrome розпізнає українську мову (`uk-UA`, потрібен інтернет).
2. Програма сама знаходить посилання: «Івана три шістнадцять», «до Римлян, восьмий розділ,
   двадцять восьмий вірш», «перше послання до коринтян 13 4», «двадцять третій псалом», «Івана 316».
3. Знайдені вірші з'являються в списку, найновіший — у попередньому перегляді.
4. Оператор натискає «Показати у LIVE» (Enter) — вірш виходить у вікно проєктора.

Ручний пошук: `ів 3 16`, `1 кор 13 4`, `пс 23`, `пс 119 105 по 112` або кілька слів з вірша.

## Біблія
`public/ogienko.json` — переклад Івана Огієнка (Public Domain), 66 книг, 31 129 віршів.
Джерело: scrollmapper/bible_databases. Підготовка: `python3 tools/build_bible.py UkrOgienko.json public/ogienko.json`
(прибирає неканонічні книги й наголоси, переводить псалми на нумерацію Огієнка: «Господь — то мій Пастир» = Пс 23).

## Розробка
```bash
npm install
npm run dev      # локально
npm test         # перевірка розпізнавання посилань (фрази в tests/parser.test.mjs)
npm run build    # збирає в ../../public/bible — потім commit + push, GitHub Pages опублікує
```

Код: `src/lib/parser.js` — розбір посилань, `numbers.js` — числа словами, `books.js` — назви книг,
`search.js` — пошук за словами, `App.jsx` — інтерфейс і вікно LIVE (`?output=1`).
