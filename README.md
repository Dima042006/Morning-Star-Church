# Сайт церкви «Світанкова Зоря» (ЦХВЄ, Рівне)

React + Vite. Дизайн — редизайн головної сторінки у стилі теми Spirixa (макет у Figma).

## Запуск

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm run build    # готова збірка в папці dist/ — її заливають на хостинг
```

`npm run build:single` збирає весь сайт в один файл `dist/index.html` (зручно, щоб швидко показати комусь).

## Де що міняти

**Увесь текст, дати, розклад, події, імена, посилання, IBAN — у файлі `src/data.js`.**
Код компонентів для цього чіпати не потрібно.

**Фото** лежать у `src/assets/images/` і підключаються вгорі `src/data.js`:

```js
import hallImg from './assets/images/hall.jpg';
export const hero = { image: hallImg, ... }
```

Щоб замінити фото, просто покладіть новий файл з тією ж назвою в `src/assets/images/`. Для нового фото — додайте файл, імпорт і впишіть його в потрібне поле. Якщо поле `image: null`, показується заглушка з підписом, яке фото там потрібне.

**Час служіння** (від нього рахується таймер трансляції і стан «Наживо зараз»): `church.service` у `src/data.js`.

## Які фото потрібні

Зараз вставлені: `hall.jpg` (перший екран), `stream.jpg` (трансляція), `record-1…3.jpg` (записи), `sunday-school.jpg`, `harvest.jpg`, `youth.jpg`, `baptism.jpg` (події); ті самі фото тимчасово стоять у стрічці Instagram.

Ще потрібні справжні фото: портрет пастора (`pastor.image`), портрети дияконів (`deacons[].image`) і пости Instagram молоді (`instagram`).

## Структура

```
src/
  data.js              ← контент сайту
  styles.css           ← кольори, шрифти, анімації, адаптив
  hooks.js             ← таймер до служіння, поява при прокрутці
  components/
    Header.jsx         ← шапка + бургер-меню, що виїжджає зліва
    Star3D.jsx         ← 3D-зірка (Three.js)
    StarMark.jsx       ← гранована зірка для логотипа
    ui.jsx             ← кнопки, заголовки з анімацією по літерах, фото
  sections/            ← блоки сторінки
```

## Що ще треба підключити

- **Пожертви.** Кнопка веде на `donate.paymentUrl`. Для щомісячної підписки підійдуть LiqPay, WayForPay або monobank-еквайринг — вони вміють регулярні платежі.
- **Форма молитовних потреб і підписка на новини** зараз лише показують повідомлення «надіслано». Найпростіше — надсилати їх у Telegram-бот церкви (див. `TODO` у `src/sections/Giving.jsx`).
- **Свята.** Дати на рік — `holidays` у `src/data.js`. Рухомі свята (Пасха, Трійця тощо) щороку інші, їх треба оновлювати на початку року.
- **Трансляція.** Плеєр веде на YouTube-канал. Коли буде постійне посилання на стрім, його можна вбудувати через `<iframe>`.

## Доступність

Сайт враховує системне налаштування «зменшити рух» (анімації вимикаються), підтримує керування з клавіатури, меню закривається клавішею Esc.

## Публікація на GitHub Pages

У проєкті вже є автоматична публікація (`.github/workflows/deploy.yml`).

1. Створіть репозиторій на GitHub і завантажте в нього **вміст** папки проєкту (разом із прихованою папкою `.github`).
2. У репозиторії: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Відкрийте вкладку **Actions** і дочекайтеся зеленої галочки (1–2 хвилини).
4. Сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Після кожної зміни файлів у гілці `main` сайт оновлюється сам.
